# Keyboard shortcuts

SUPER = Windows key. On the laptop: **SUPER + H** shows this list (searchable), **SUPER + F1** opens the help center.

```
## Apps
  SUPER + Enter              Terminal (kitty)
  SUPER + D                  App launcher (search by name)
  SUPER + A                  Apps by category (with descriptions)
  SUPER + H                  Help: all keyboard shortcuts
  SUPER + F1                 Help center (shortcuts, apps guide, Linux basics)
  SUPER + SHIFT + D          Run command
  SUPER + B                  Browser (Zen)
  SUPER + CTRL + B           Firefox (fallback)
  SUPER + X                  Claude Code (AI assistant in the terminal)
  SUPER + SHIFT + X          Claude in browser (claude.ai)
  SUPER + CTRL + N           Night light on/off
  SUPER + CTRL + P           Color picker (copies color)
  SUPER + CTRL + M           Dismiss all notifications
  SUPER + CTRL + R           Restore last notification
  SUPER + CTRL + D           Do not disturb on/off
  SUPER + W                  Next wallpaper
  SUPER + SHIFT + W          Live data rain on/off (AC only)
  SUPER + =                  Calculator (qalc)
  SUPER + CTRL + Enter       Floating terminal
  SUPER + E                  File manager (yazi)
  SUPER + C                  VS Code (IDE)
  SUPER + J                  JupyterLab (notebooks)
  SUPER + N                  Network (nmtui)
  SUPER + SHIFT + A          Audio mixer
  SUPER + Y                  Bluetooth
  SUPER + SHIFT + T          System monitor (btop)
  SUPER + V                  Clipboard history
  SUPER + M                  Mouse from keyboard (hints)
  SUPER + F10                Eco mode on/off (max battery)

## Session
  SUPER + Esc                Lock screen
  SUPER + SHIFT + E          Power menu
  Fn key (PowerOff)          Power button: menu
  SUPER + SHIFT + R          Reload Hyprland config

## Windows
  SUPER + Q                  Close window
  SUPER + F                  Fullscreen
  SUPER + Space              Floating / tiled
  SUPER + P                  Pseudotile
  SUPER + T                  Toggle split direction

## Windows: arrow keys
  SUPER + arrows             Focus window left/right/up/down
  SUPER + SHIFT + arrows     Move window
  SUPER + CTRL + arrows      Resize window (hold to repeat)
  ALT + Tab                  Next window

## Workspaces
  SUPER + 1..0               Go to workspace 1..10
  SUPER + SHIFT + 1..0       Move window to workspace 1..10
  SUPER + Tab                Next workspace
  SUPER + SHIFT + Tab        Previous workspace
  SUPER + ]                  Next workspace
  SUPER + [                  Previous workspace
  SUPER + S                  Scratchpad on/off
  SUPER + SHIFT + S          Send window to scratchpad

## Screenshot
  Print                      Screenshot (full)
  SUPER + Print              Screenshot (region)
  SUPER + SHIFT + Print      Screenshot + annotate (satty)
  SUPER + CTRL + Print       Screen recording on/off
  SUPER + ALT + Print        OCR region to clipboard

## ThinkPad Fn keys
  Fn key (AudioRaiseVolume)  Volume up
  Fn key (AudioLowerVolume)  Volume down
  Fn key (AudioMute)         Mute
  Fn key (AudioMicMute)      Mute microphone
  Fn key (MonBrightnessUp)   Brightness up
  Fn key (MonBrightnessDown) Brightness down
  Fn key (AudioPlay)         Play/Pause
  Fn key (AudioNext)         Next track
  Fn key (AudioPrev)         Previous track
```
